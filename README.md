# HOTSET Browser — Next-Generation Universal Web Browser

**One Browser. Every Device. Limitless Possibilities.**

HOTSET Browser is a universal, AI-native, privacy-first web browser engineered for Android, iOS, Windows 10/11, macOS, Linux, Tablets, and Foldable devices.

## Key Features
- **Universal Cross-Platform Architecture:** Shared futuristic glassmorphic UI with native rendering bridges (Chromium/Blink on Windows, Linux, Android; WKWebView on macOS and iOS).
- **Complete Design System:** Midnight, Dark, AMOLED Pitch Black (`#000000`), Light, and System Auto themes, dynamic neon accents, custom wallpapers, and Compact/Comfortable/Spacious density controls.
- **Advanced Tab & Workspace Engine:** Horizontal and Vertical tabs, color-coded Tab Groups (`Work`, `Dev`, `AI`, `Finance`), Pinned Tabs, Automatic Tab Hibernation (RAM Saver), Split-Screen Dual-Pane browsing, and Recently Closed Tab restoration.
- **Unified Smart Omnibox:** Multi-engine switching (Google, DuckDuckGo, Brave, Bing, Wikipedia, Custom), `@g` / `@ddg` / `@brave` / `@wiki` shortcuts, instant math evaluation, Voice Search, and SVG QR Code Generator/Scanner.
- **Zero-Trust Privacy Shield:** Built-in tracker and ad blocking, HTTPS-First auto-upgrade, DNS-over-HTTPS (Cloudflare 1.1.1.1, Quad9, NextDNS), Stealth Private Mode, and WebCrypto AES-256-GCM Password Vault.
- **HOTSET Neural AI Co-Pilot:** One-click page summarization, technical explanation, multi-tab comparison table, and multi-language translation (Bengali, English, Hindi, Spanish, Japanese).
- **Productivity & 13-Module Settings Center:** Multi-threaded Download Manager with Pause/Resume, Distraction-Free Reader Mode with Text-to-Speech, Page Screenshot capture, Sticky Notes, Picture-in-Picture media deck, built-in DevTools Console, and E2EE Cloud Sync.

## Build & Run Commands
- **Universal Web / PWA:** `npx serve src`
- **Desktop (Electron — Windows/macOS/Linux):** `npm run start:desktop`
- **Android APK & App Bundle:** `npm run cap:android`
- **Automated Test Suite (15/15 Passing):** `python3 tests/test_hotset_browser.py`
